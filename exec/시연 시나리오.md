# 우주인(Woojuin) 시연 시나리오

> SSAFY 15기 광주 1반 공통 프로젝트 C105 / 우주인
> 저장은 1초, 정리는 AI가, 찾을 땐 검색 한 번.

본 문서는 발표 시연의 **화면별·실행별 상세 안내서**다. 각 장면마다 어떤 화면에서 어디를 클릭하고 무엇을 말하는지 순서대로 적었다.

## 0. 시연 개요

### 전체 흐름

| 4 | 모바일 인스타그램 공유로 저장 | 모바일 담당자 | Discord 화면 공유 |

### 콘셉트

처음에는 **개인 스페이스**에서 우주 뷰·대시보드 뷰·지도 뷰·테마 전환과 데이터 추가(링크/사진/텍스트) 기능을 짧게 소개한다. 실제 저장과 검색은 뒤에서 보여준다.

이후 **아무 데이터도 없는 C105팀 스페이스**로 이동해 상황을 설명하고, 크롬 익스텐션·모바일·MM을 통해 음식·맛집, 놀거리·체험, 아이디어·영감 데이터를 저장한다. WearOS 시연 후 다시 C105팀 스페이스로 돌아와 새롭게 채워진 우주와 AI 정리 결과를 확인하고, 일반 검색과 AI 검색으로 마무리한다.

### 화면 구성 (시연자 PC)

윈도우 창 3개를 미리 띄워 두고 `Alt + Tab` 없이 작업 표시줄로만 전환한다.

1. **PPT** — 발표 자료
2. **우주인 시연** — Chrome (익스텐션 설치된 프로필)
3. **Discord** — 모바일·MM 담당자 화면 공유 수신

### 화면 요소 위치 (데스크톱 기준)

시연은 전부 데스크톱 웹에서 진행한다. 클릭 대상은 아래 두 곳에 모여 있다.

- **헤더 우측 묶음** — 왼쪽부터 `멤버 아바타 → 워크스페이스 설정(기어) → 휴지통 → 데이터 추가(+) → 테마 → 뷰바`
  - 멤버 아바타와 설정 기어는 **공유 스페이스에서만** 보인다(개인 스페이스에는 없다).
  - **뷰바**가 `성좌 / 대시보드 / 지도` 아이콘 3개다. 뷰 전환은 전부 여기서 한다.
- **좌측 사이드바** — 맨 위 `Personal Space`, 그 아래 워크스페이스 목록. 스페이스 전환은 여기서 한다.

검색창은 화면 **하단 중앙에 고정**되어 있고, 우측 끝에 AI 모드 토글이 붙어 있다.
